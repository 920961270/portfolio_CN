VSRNet 问题

为什么关注振动退化视频复原？

问题

振动会在监控视频中造成模糊、局部形变和帧间不稳定。

挑战

画面更清晰并不够。工业视觉系统还需要时序稳定性和可靠的下游感知结果。

我的关注点：从三个视角评估复原效果

重建保真度
运动稳定性
下游检测一致性

RAG + LLM 设计

用保守工程控制实现有依据的报告生成

RAG + LLM 设计

知识层 VSRNet 文档、方法笔记、评估说明
检索层 SentenceTransformers 嵌入 + FAISS 索引 + top-k 检索
报告层 规则化指标解释 + 可选 LLM 补充分析

工程经验

路径鲁棒性子进程推理使用明确路径，减少运行环境差异。
复用模式跳过耗时阶段，快速重新生成报告。
指标可靠性区分数据不可用和逻辑未实现。
LLM 安全性保存原始输出，清理风险表述，校验最终文本。

规则分析是事实来源。LLM 输出只作为可选补充，并通过清理与校验减少无依据表述。
