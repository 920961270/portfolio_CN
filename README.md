# 计算机视觉 + RAG/LLM 工程作品集

这是陈陆琪面向算法、LLM 与机器学习工程岗位的中文静态 HTML 作品集。

## 本地预览

直接用浏览器打开 `index.html`。

## GitHub Pages 部署

1. 将本目录作为仓库内容推送到 GitHub。
2. 进入 Repository Settings -> Pages。
3. 选择 Deploy from branch -> `main` -> root。
4. 保存设置。

如果仓库名为 `portfolio_CN`，预期访问地址类似：

https://920961270.github.io/portfolio_CN/

## 说明

这是一个静态 HTML/CSS/JS 作品集页面。无需后端、登录、API key 或构建步骤。

GIF 资源使用相对路径：

- `gifs/low_compare.gif`
- `gifs/mid_compare.gif`
- `gifs/high_compare.gif`

## 简历链接写法建议

中文简历可写：

项目作品集：在线 HTML Portfolio

英文简历可写：

Project Portfolio: Online HTML Portfolio

或：

Project Portfolio: Technical Project Portfolio

不建议在简历中写成特定公司的 Portfolio，这样作品集可以复用于更多算法和机器学习工程岗位。
